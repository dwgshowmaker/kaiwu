# 论文思路落实清单

## 目的

这份文档把前面参考经典论文得到的思路，和当前 `agent_diy` 的实际落地状态逐项对齐。

分类方式：

- 已经实现
- 准备实现
- 暂不打

长期目标仍然是：

- `PPO + GRU/LSTM`

但当前主线依旧停留在 `Phase2`。

## 一、已经实现

### 1. PPO / GAE 长时序 credit assignment 调整

状态：已实现

当前落地：

- `Config.GAMMA = 0.995`
- `Config.LAMDA = 0.97`
- `GAE` 显式使用 `done mask`
- PPO batch 内对 `advantage` 做归一化
- 对关键阶段样本引入 `credit_weight`

对应论文/经典思路：

- PPO
- GAE

当前价值：

- 让 `450-550` 这段关键准备期和加速期对训练更新更有影响力

### 2. 更彻底的 potential-based shaping

状态：已实现

当前落地：

- `state_potential`
- `safety_potential`
- `resource_potential`
- `flash_potential`
- `readiness_potential`
- 主 shaping 继续按 `gamma * Phi(s') - Phi(s)` 组织

对应论文/经典思路：

- potential-based reward shaping

当前价值：

- 把 `500` 前准备和 `500` 后生存统一到一条更稳定的 shaping 主线

### 3. 保留硬 mask，退火手工 prior

状态：已实现

当前落地：

- `legal action mask` 保留
- `safe_prior / prep_prior` 保留
- 新增 `safe_prior_scale / prep_prior_scale`
- 按累计观测步数退火

对应论文/经典思路：

- invalid action masking
- 手工启发式逐步退场的工程化做法

当前价值：

- 前期稳样本，后期避免一直靠先验兜底

### 4. 更强的空间观测表达

状态：部分实现

当前落地：

- 环境原始 `map_info` 是 `21x21`
- 模型实际输入已从单一 `7x7` 升级到 `coarse 7x7 + center 11x11`

对应论文/经典思路：

- 空间观测需要更合理的表示，而不是只靠过粗压缩

当前价值：

- 这是后续 `21x21 + CNN` 之前的过渡版

## 二、准备实现

### 1. PPO + GRU/LSTM

状态：准备实现，长期目标

为什么还没上：

- 现在最关键的是先把非递归版 `Phase2` 指标收稳
- 否则后面很难判断收益到底来自记忆分支，还是来自前面基础策略本身

计划进入条件：

- `550+` 和 `600+` 不再只是偶发
- `buff_ready_at_speedup` 明显抬升
- `safe_prior` 退火后分数还能稳住

### 2. 21x21 + CNN 地图分支

状态：准备实现，但优先级低于 `GRU/LSTM`

为什么还没上：

- 当前已经先做了多尺度 MLP 过渡版
- 需要先看这版能不能继续推高 `550+ / 600+`

计划进入条件：

- 多尺度输入长期仍卡在 `550-600`
- `blocked / stuck / flash_trap` 继续说明近身地形判断是瓶颈

### 3. 窄范围 curriculum

状态：准备实现，建议支线试验

具体方向：

- 不做大范围 `Phase3` 随机化
- 只围绕 `420-550`
- 只围绕 `500` 加速点
- 只围绕 `buff/flash` 备战

计划用途：

- 如果主线 `Phase2` 收尾明显平台期，再用它辅助突破

### 4. 分层动作

状态：准备实现，但优先级更靠后

具体方向：

- 高层：`escape / prep_buff / normal_collect / flash_escape`
- 低层：方向

为什么靠后：

- 当前更紧迫的问题还是时序记忆和空间表达
- 平铺 `16` 动作虽然有上限问题，但还没到最先动它的时候

## 三、暂不打

### 1. 全量 Phase3 和 Phase4 绑定推进

状态：暂不打

原因：

- 会把“环境分布变化”和“模型结构变化”混在一起
- 后面很难归因提升或回退到底来自哪一边

### 2. 大力度 intrinsic exploration

状态：暂不打

包括：

- curiosity bonus
- count-based exploration

原因：

- 你现在不是纯稀疏奖励问题
- 当前主矛盾是 `500` 前准备与 `500` 后生存
- 这类方法容易把主任务带偏

### 3. 直接把 21x21 全扁平喂给 MLP

状态：暂不打

原因：

- 信息虽然更全，但对纯 MLP 不够友好
- 更合理的方向是后续上 `21x21 + CNN`

## 当前推荐顺序

1. 先继续验证 `Phase2.9`
2. 如果 `550+ / 600+ / buff_ready_at_speedup` 继续上升，就再收一轮 `Phase2`
3. 如果 `Phase2.9` 开始明显平台期，就优先进入 `PPO + GRU/LSTM`
4. 如果平台期同时伴随近身地形判断仍差，再补 `21x21 + CNN`
5. 再之后考虑窄范围 curriculum
6. 分层动作放在更后面
